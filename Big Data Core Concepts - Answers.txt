### Questions

# Q: What is interactive computing?
A: Interactive computing is a term used to describe programs that accept input from the user during their runtime.

# Q: What is Ad hoc analysis?
Some important data is not normally comfortably reported in data reports, ad hoc analysis refers to getting that data using one off questions.
Usually used for very specific things and short term queries.

# Q: What is a Lakehouse?
Implemented upon a Data Lake. Combines concepts of both data lake and data warehouse, trying to get the best of both worlds. We store inside of it all types of data.
It's faster to access than a data lake, and cheaper than a warehouse. 

# Q: Difference between Lakehouse and RDBMS and when to use
RDMBS is a database management system that stores data in a strict schema using rows and columns. If you only have structured data then you should use RDBMS which also
gives you the advantage of easily working with SQL, if you have lots of unstructured data it's probably better to use a lakehouse or data lake.

# Q: What is ERD?
ERD, Entity Relationship Diagram is a standard graphical model used to explain relationships between objects using shapes and arrows.

# Q: Parquet vs Json
They have different data formats, json is text based, you can read it yourself, unlike parquet which is binary columnar storage and not readable.
But parquet is more efficient, it has faster serialization than json and is more compact. Also parquet is better if we mainly use read I/O operations,
since if we have many write operations it becomes less optimized since the entire column needs to be rewritten when the file is updated. 

# Q: In masterful do read calls pass through the master?
No, only happens temporarily if all slaves are down before a new one is created, but in general the read calls go directly to the slaves.


# Q: How does synchronization work in masterless?
At all time everyone is informed if they are in sync or not (Or through some time based algorithm), if there is no sync, then those who need to
update accordingly do so. When they inform each other if they are in sync or not, each unit informs each unit if they are in sync with themselves.

# Q: Datalake vs Dataswamp
A dataswamp is a disorganized and messy data lake. It's a data lake that shows the signs of being disorganized, has poor data quality, security issues,
or even simply inaccessible. A dataswamp is unmanagable and impossible to work with.
